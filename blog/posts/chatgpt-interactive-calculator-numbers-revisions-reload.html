OpenAI & ChatGPT November 4, 2026

ChatGPT built a calculator in its answer. Here’s how we checked it.

We checked a ChatGPT calculator’s numbers, changed one ingredient and reloaded the chat. The response returned, but its selected serving value reset.

An answer can be more useful when you can change an input and see the result. In our Run #7 experiment, ChatGPT returned a small interactive recipe-scaling calculator directly in the chat response. We used the control, checked the numbers, changed a starting fact and reopened the saved conversation.

This was a fictional arithmetic example, not a cooking recommendation. It was also one observed experiment in our account, with Chat mode and Instant selected. It does not establish that every prompt or account will return the same interface.

Start with facts you can check

Our two-serving base was 150 grams of rice, 300 milliliters of water and 100 grams of peas. We asked for a servings control from one to eight, visible units and the scaling rule, directly inside the answer. We did not build a separate website.

At two servings, the displayed quantities matched those starting facts. At eight, the original calculator showed 600 grams of rice, 1,200 milliliters of water and 400 grams of peas. Independently, eight divided by two gives a multiplier of four. Each starting quantity multiplied by four matched the displayed result. At one serving, the quantities halved correctly: 75 grams, 150 milliliters and 50 grams.

Those checks support this particular calculator. They do not guarantee the correctness of every interactive answer.

A changed fact created another version

Next, we asked for a two-serving rice base of 180 grams while keeping water and peas unchanged. The follow-up produced a separate calculator below the first and labeled the updated base.

At eight servings, the revised rice quantity was 720 grams. Water and peas stayed at the original eight-serving quantities. The meaningful test was whether the calculation actually used the changed fact while preserving the unchanged ones. It did in this experiment.

The original calculator remained above it. If a conversation contains several versions, check which response you are using.

A saved response is different from a saved selection

Reset returned the original calculator to two servings. We then selected eight and reloaded the saved chat. After loading settled, the calculator returned at two servings. Our selected eight had not survived.

The transient loading state was not evidence that the response had disappeared. The settled result was narrower: the response returned, while the selected value reset. Before relying on an adjusted tool later, reopen it and check the settings that matter.

Narrow browser checks are not physical-phone tests

We checked the original calculator in 400- and 360-pixel browser views. Labels and quantities fitted. The control worked at 400 pixels, and Reset worked at 360. We had to scroll to see the whole tool.

These were desktop browser simulations, not tests on a physical phone or in the mobile app. A useful desktop result still deserves a check on the device where you intend to use it.

Try a small task you already understand

Give ChatGPT the starting facts, name the control you want, and ask it to show the rule and units. Then check one easy result, change one starting fact, and reopen the chat. These checks tell you more about whether the tool fits the job than appearance alone.

We found the interactive answer useful for this small test. We have not established that it replaces a dedicated app, or that another prompt will produce the same layout.
